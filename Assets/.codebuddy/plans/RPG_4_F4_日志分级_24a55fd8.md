# RPG_4 · F4 日志分级（精简版）

## 1. 一句话需求

在 `e:/ue/RPG_4` 的 `Assets/backpack/` 内落盘 F4 的**日志子集**，建立全工程唯一日志出口；`GridUtils` 因依赖 F3 的 `GridCoord`，延后到 F3 落盘后补齐。

## 2. 它在背包系统中承担什么

| 维度 | 作用 |
| --- | --- |
| 定位 | 数据层 / 网络层 / UI 层**共用的横切基础设施**，属 F 框架层，不参与任何业务逻辑 |
| 解决的问题 | 多人背包的排查痛点是「同一帧里 Inventory、Equipment、UI、Network 四个子系统都在刷日志」。本模块用**模块位掩码 + 六级严重度**双维度过滤，只开你要的那个子系统与级别 |
| 上游输入 | 无（`Core` 程序集 `references: []`，日志四文件零依赖，不碰 F3 类型） |
| 下游消费者 | M1–M9 全阶段：`Items/Inventory → LogModule.Inventory`、`Equipment → Equipment`、`UI → UI`、网络复制 → `Network`。路线图硬约束：**禁止裸调 `UnityEngine.Debug` 或 `print()`** |
| 验收价值 | 数据层「无 UI 也能跑通」的单测/纯逻辑环境下，日志是唯一的可观测手段 |

## 4. 四个文件的功能契约

**`LogLevel`（六级，数值即严重度）**
`Trace=0 / Debug=1 / Info=2 / Warn=3 / Error=4 / Fatal=5` → 直接用 `level >= minimumLevel` 做过滤。

**`LogModule`（`[Flags]` 位掩码）**
`None=0`，`Inventory=1<<0`、`Equipment=1<<1`、`UI=1<<2`、`Network=1<<3`、`Interaction=1<<4`、`Combat=1<<5`、`SaveLoad=1<<6`，`All=~0`。
不移植蓝本的 `AI / DataAsset / Config / Custom1~4`（零调用点）。

**`LogSettings`（ScriptableObject，Inspector 可勾选）**
字段：`isEnabled`(true) / `minimumLevel`(Info) / `enabledModules`(All) / `useTimestamp`(true) / `includeStackTrace`(false)。
判定链（三条件全通过才输出）：
`IsEnabledFor(module, level) = isEnabled && level >= minimumLevel && (enabledModules & module) != 0`
另带 `CreateRuntimeDefault()`（`HideAndDontSave` 临时实例，不落盘）作兜底。

**`BackpackLog`（静态门面，全工程唯一出口）**

- API：六级 × 2 版本（`string` / 惰性 `Func<string>`）= 12 个，另加 `Error/Fatal(Exception)`。
- 资产解析优先级：① 显式注入 `BackpackLog.Settings = asset` → ② `Resources.Load("LogSettings")` 兜底（本阶段只留钩子，不建 `Resources/`）→ ③ 运行时默认值。
- 惰性版在开关未通过时**不调用工厂**（热点路径零字符串拼接）。
- 全部方法体包 `#if UNITY_EDITOR || DEVELOPMENT_BUILD` → Release 构建零开销。
- 类内一律写全限定 `UnityEngine.Debug.XXX`，避免与自身 `Debug(module, msg)` 重名歧义。
- `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` 复位静态 `settings`，兼容「关闭 Domain Reload」。
- 输出映射：`Trace/Debug/Info → Debug.Log`，`Warn → LogWarning`，`Error/Fatal → LogError`。

| 日志分级可用 | 六级 × 2 版本全部可调；资产在 Inspector 可见、字段可勾选；关掉全局开关后零输出 |

## 7. 唯一高风险点

`Data/LogSettings.asset` 的 `m_Script.guid` 必须指向本次新建的 `LogSettings.cs.meta`。蓝本的 `d4f6ca318e257091db1f347a5ce6b234` **不能沿用**，照抄会导致脚本引用悬空、资产显示为 Missing Script。
