## 需求概述

在 RPG_4 中先只落地一对最小的背包数据关系：抽象物品父类、储存数据类（角色身上具体物品的集合）、背包类（格子数组 → 集合下标的映射）。本轮只做「映射 + 读取」，不做任何写操作。

## 范围替换说明

本方案替换此前的「物品数据层（M1）13 文件照搬计划」：原计划本轮作废、不再执行；不实现片段 / 清单 / 快照等体系，仅实现上述三类型的最小设计。

## 核心功能

1. 物品父类（抽象）：承载类型标签、数量、占格宽高（支持多格）；只定义公共数据与构造校验，不实现任何具体物品子类。
2. 储存数据类：持有角色身上具体物品的集合，提供只读枚举与按下标 / 按实例查询。
3. 背包类（映射核心）：一个长度等于背包宽 × 高的格子数组，每格记录该格物品在数据类中的下标，-1 表示空格；多格物品的每个占格都指向同一物品。
4. 读取能力：格 → 物品、物品 → 全部占用格（含上左格）、是否占用、占用 / 空位统计、映射一致性校验（只读）。
5. 交付边界：仅新增代码文件、不改动任何既有内容；编译通过且控制台无错误即验收。放置 / 移除 / 交换 / 堆叠等操作与任何界面内容均不在本轮。

## 技术栈与现状

- 工程：Unity 2022.3.62f3 LTS + URP 14，纯 C#，无第三方依赖；本轮零新包、零 asmdef 改动。
- 程序集已就位：`Assets/backpack/Scripts/Items/` = `RPG4.Backpack.Items`（引用 Core）；`Assets/backpack/Scripts/Inventory/` = `RPG4.Backpack.Inventory`（引用 Core + Items）。两目录当前均无 .cs 文件，本轮全部为新增。
- 复用 Core 基建（已逐文件核实存在）：`BackpackTag`（IsEmpty / IsValid / Name / 等值）、`GridCoord`（X / Y / IsValid，可作尺寸语义）、`GridUtils`（GetIndexFromPosition / GetPositionFromIndex / IsInGridBounds，行优先 Y × Columns + X）。
- 工程口径：命名空间 RPG4.Backpack.*；公开成员中文摘要注释（同 BackpackTag.cs / GridCoord.cs）；.meta 手工维护、新 GUID 为 32 位十六进制且工程内唯一；UTF-8；零单测。

## 实施策略

本轮为自研最小映射层，不存在蓝本对照物；蓝本 `ZDXT2/Assets/backpack/Scripts/Inventory/InventoryContainer.cs`、`InventoryPlacement.cs` 仅作语义参考，不做照搬。关键决策：

1. 三层职责分离：抽象物品父类（数据外壳）→ 储存数据类（物品集合，只读）→ 背包类（格子数组 → 集合下标 的映射，只读）；依赖方向 Items 被 Inventory 引用，无循环。
2. 映射语义（按用户定调）：cells 长度 = Width × Height；值 = 该格物品在 BackpackData 中的下标，-1（Backpack.NoIndex）为空格；多格物品的每个占格写同一下标；上左格 = 占格中的最小线性索引（行优先下必为矩形左上角）。
3. 构造即唯一数据入口：构造期做防御性拷贝（外部数组后续改动不影响内部状态）+ 范围校验 + 一次性预计算占用 / 空位统计；「矩形几何一致性」交给只读 TryValidateMapping，构造不强制。
4. 零写操作：不提供放置 / 移除 / 交换 / 堆叠；不暴露原始数组。
5. 反向查询（物品 → 格子）线性扫描 + 调用方 buffer 复用（零分配）；不建缓存（YAGNI）；最坏成本由 65536 格上限（256 × 256，沿用蓝本 MaxSlotCount 口径）兜底。

## 架构与数据流

BackpackData 由物品序列构造（角色身上具体物品集合）；Backpack 构造时注入 (Data, 宽, 高, cells 数组)。读取链：格子线性下标 → cells[i] → BackpackData 下标 → BackpackItem；反向链：BackpackItem → 集合下标 → 扫描 cells 收集格子。无 UI / 网络 / 资产依赖，可在无场景环境下使用。

## 关键契约（签名级，实现必须一致）

```
// 文件 1：Scripts/Items/BackpackItem.cs —— 命名空间 RPG4.Backpack.Items
public abstract class BackpackItem
{
    protected BackpackItem(BackpackTag itemType, int stackCount, GridCoord size);
    public BackpackTag ItemType { get; }   // 非空且格式合法
    public int StackCount { get; }         // ≥ 1
    public GridCoord Size { get; }         // X、Y ≥ 1（宽 X、高 Y）
}

// 文件 2：Scripts/Inventory/BackpackData.cs —— 命名空间 RPG4.Backpack.Inventory
public sealed class BackpackData
{
    public BackpackData(IEnumerable&lt;BackpackItem&gt; items);
    public IReadOnlyList&lt;BackpackItem&gt; Items { get; }
    public int Count { get; }
    public bool TryGetItem(int index, out BackpackItem item); // 下标越界返回 false
    public int IndexOf(BackpackItem item);                    // 不在集合返回 -1
    public bool Contains(BackpackItem item);
}

// 文件 3：Scripts/Inventory/Backpack.cs —— 命名空间 RPG4.Backpack.Inventory
public sealed class Backpack
{
    public const int NoIndex = -1;
    public const int MaxCellCount = 65536;
    public Backpack(BackpackData data, int width, int height, int[] cellItemIndices);
    public BackpackData Data { get; }
    public int Width { get; }
    public int Height { get; }
    public int CellCount { get; }
    public int OccupiedCellCount { get; }  // 构造期预计算
    public int EmptyCellCount { get; }     // 构造期预计算
    public bool IsCellIndexValid(int cellIndex);
    public bool IsCellOccupied(int cellIndex);        // 非法索引返回 false
    public int GetItemIndexAt(int cellIndex);         // 空格或越界返回 NoIndex
    public BackpackItem GetItemAt(int cellIndex);     // 空格或越界返回 null
    public BackpackItem GetItemAt(GridCoord coord);   // 坐标越界返回 null
    public bool Contains(BackpackItem item);          // 已登记且至少占一格
    public bool TryGetUpperLeftIndex(BackpackItem item, out int upperLeftIndex);
    public bool TryGetCellIndices(BackpackItem item, List&lt;int&gt; buffer); // 先 Clear、升序填充；未在背包返回 false 并清空
    public bool TryValidateMapping(out string error);
}
```

## 校验清单

- Backpack 构造：data 非空；width / height &gt; 0；width × height（long 探测溢出）≤ 65536；数组非空且长度 == Width × Height；每个值 ∈ {-1} ∪ [0, data.Count)，违规即失败。
- BackpackData 构造：items 非空；元素不得为 null；同一实例不得重复登记。
- BackpackItem 构造：ItemType 非空且格式合法；StackCount ≥ 1；Size.X / Size.Y ≥ 1。
- TryValidateMapping：逐物品收集其占格；无占格（未放入本背包）跳过、不算错；有占格时占格数 == Size.X × Size.Y 且自最小索引起按行列展开全部命中同一物品，否则返回 false 并给出可诊断 error。
- 失败一律抛 ArgumentException 家族（空引用 / 数值域 / 结构不符分别用 ArgumentNullException / ArgumentOutOfRangeException / ArgumentException），错误信息用中文。

## 实施要点与风险控制

1. .meta：逐字符复制骨架（含 `userData:` 等三行的行尾空格）；GUID 生成后全 Assets 检索 `guid: 新值`，命中数须恰为 1。
2. 注释沿用仓库既有口径（公开成员中文摘要注释）；skill 的「不加注释」不覆盖该既有口径，且不添加超出该口径的额外注释。
3. 编码 UTF-8；全程不运行测试、不建测试工程、不改 asmdef、不动 Core / Data / Docs 与任何既有文件；若 Unity 报错，修正仅限本轮 3 个新文件。
4. 爆炸半径 = 仅 6 个新文件，无既有引用者；唯一衔接风险是与 Core 的符号对接，落盘后逐符号核对（BackpackTag.IsEmpty / IsValid、GridCoord.X / Y、GridUtils.GetIndexFromPosition / IsInGridBounds 均已存在）。
5. 验收：执行侧静态核对（GUID 唯一、命名空间 / using / 签名与契约一致、既有文件零改动）；用户在 Unity 刷新确认编译通过、Console 无错误。本轮无具体子类、运行期不可实例化，属预期。
6. 性能：构造 O(CellCount)；格查询 O(1)；反向查询 O(CellCount)（buffer 复用零分配）；占用 / 空位为构造期预计算属性；无每帧分配与全局状态。
