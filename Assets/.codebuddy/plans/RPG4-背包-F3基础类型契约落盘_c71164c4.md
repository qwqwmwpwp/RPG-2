# RPG4 背包 · F3 基础类型契约落盘

## 一、需求

在 `e:/ue/RPG_4` 落盘 F3 基础类型契约（6 个类型）+ 补齐 F4 余量 `GridUtils.cs`，并把命名空间/程序集名统一改为 `RPG4.Backpack.*`，同步三份文档。

## 二、已定决策

1. **零单测**（用户选定）：不建 Tests asmdef、不写 EditMode 用例；验收降级为静态核对 + Unity 编译确认。蓝本 F3 规范第 6 节的「单测硬断言」口径须改写并记录取舍。
2. **F3 + GridUtils 合并交付**：蓝本 F3 契约第 5 节硬约束「换算只接受 `GridCoord`」，类型到位即可写，一次 Unity 往返完成。
3. **命名空间改 `RPG4.Backpack.Core`**；连带把 Core/Utils 已有 4 个文件一并改名（越晚成本越高）。
4. **推导决策（可否决）**：RPG_4《F1_F2 规范》第 3.1 节规定「命名空间与程序集同名」，故 5 个 asmdef 的 `name` / `rootNamespace` / 文件名 / 跨程序集 references 字符串一并改 `RPG4.Backpack.*`。若只想改命名空间，则退化为仅改 4 个 `.cs` + 文档措辞。
5. **逐行照搬蓝本**：唯一差异是命名空间声明；枚举数值、空态哨兵、class/struct 之分、泛型约束、注释全部保留，不重写、不加蓝本以外注释。

## 三、交付物
