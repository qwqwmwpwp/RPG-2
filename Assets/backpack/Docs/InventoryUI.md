# 背包界面

统一入口为 `Assets/Scenes/Main.unity`，同时集成玩家移动、相机、背包窗口与箱子交互。

当前界面以 UGUI 预制体保存窗口框架和引用。场景中的 `UIManager` 持有窗口根节点及窗口预制体；运行时创建窗口并统一开关。`背包UI.prefab` 用于个人背包，`和箱子交互ui.prefab` 用于个人携行与外部容器的双栏窗口。两者共用 `InventoryGridView.prefab` 网格、`物品ui.prefab` 物品视图和 `ItemDetails.prefab` 详情浮层。

`Main.unity` 放置红药水 ×3 与火蕨果 ×12 作为单机 `WorldPickup` 示例；配置错误或背包无法完整接收时保留地面物品，成功接收后才隐藏。联机世界拾取尚无服务端验证链路，因此网络会话会拒绝该本地交互。

## 框架规划

| 框架 | 当前职责 | 后续扩展边界 |
| --- | --- | --- |
| 窗口外框 | 顶栏、关闭入口、内容区域与底部反馈；固定节点保存在窗口预制体 | 分辨率与排版调整留在预制体，不承担物品操作 |
| 携行区域 | 显示玩家网格、占格与数量摘要 | 装备和快取袋接入后增加独立视图与数据来源，不向网格类塞装备规则 |
| 外部容器区域 | 显示本次打开的箱子，沿用双栏转移 | 尸体、掉落袋及搜索进度需要对应数据来源与玩法状态后再接入 |
| 详情浮层 | 读取悬停物品，显示实际属性；独立于网格裁剪区域 | 物品使用、装备比较分别交给对应业务，不在详情组件中变更库存 |
| 操作与反馈 | 输入路由提交到交互会话；完整库存事务处理变更；展示组件读取结果 | 新增操作继续走完整事务，避免 UI 自行组合扣减和增加数量 |
| 局外仓库 | 本期不新增窗口 | 后续复用网格与详情，单独承担搜索、排序和配装流程 |

## 组件职责

- `UIManager` / `UIBase` 管理窗口注册、打开、关闭、互斥、置顶和 `CanvasGroup` 显隐。
- `InventoryUICoordinator` 统一接收箱子开窗事件、执行背包开关策略，并提供当前活动窗口和交互会话；外部展示请求在此转换成窗口调用。
- `BackpackGridUI` 与 `ChestBackpackUI` 负责取得库存来源，只在打开期间绑定容器和维护交互会话；关闭时解绑、退订并恢复输入与光标。重复请求同一箱子保留当前会话，切换来源时先清理旧交互。
- `BackpackContainerUI` 只显示绑定的库存、格子、物品和容量摘要数据；`viewport` 限定鼠标命中范围。
- `BackpackInteractionController` 处理悬停、携带预览和库存操作请求。位置由库存唯一持有；`InventoryGridLayout` 只读投影权威放置记录，UI 不保存独立排布。移动、交换、合堆、拆分和转移均提交完整库存操作。
- `InventoryUIInputRouter` 订阅背包输入动作，把开关键交给协调器，并把指针和点击转发到协调器提供的当前会话；不判断具体窗口类型。
- `BackpackScrollRect` 管理网格视口滚动；携带物品或等待库存操作时停止内容拖动。
- `BackpackWindowUIData` 保存固定框架的组件引用；`BackpackWindowPresentation` 更新容量摘要、操作提示、状态消息和详情浮层。
- `BackpackItemDetailsUI` 只读显示物品名称、中文类别、占格、堆叠数量及已支持片段属性，不执行物品使用或装备。

## 预制体层级与接线

两个窗口根节点都带 `CanvasGroup`、对应的 `UIBase` 派生窗口组件、`BackpackInteractionController`、`BackpackWindowUIData` 和 `BackpackWindowPresentation`。根下保存顶栏、标题、副标题、关闭按钮、容器标题、容量摘要、视口、操作提示和状态消息；个人背包有一个玩家视口，双栏窗口有玩家与外部容器两个视口。每个视口以 `RectMask2D` 裁切显示区域，挂载连接交互控制器的 `BackpackScrollRect`，并包含网格预制体实例。携带预览使用根级 `CursorLayer`（双栏窗口为 `SharedCursorLayer`），详情浮层作为根级子节点保存。

`BackpackWindowUIData` 的 `window`、容器视图、交互控制器、摘要与提示文本、详情浮层均由预制体序列化引用。关闭按钮的 `Button.onClick` 指向同一预制体窗口的 `Close`。每个容器视图需连接格子预制体、物品预制体、格子层、物品层、显示字体及视口；双栏窗口还需将左右视图和标题接入 `ChestBackpackUIData`。场景 `UIManager.windowRoot` 指向 Canvas，`windowPrefabs` 指向这两个窗口预制体；同物体预先挂载 `InventoryUICoordinator` 和 `InventoryUIInputRouter`，无需在运行时创建控制组件。

## 已实现操作

- 按 `B` 打开个人背包；已有库存窗口打开时再次按 `B` 关闭当前窗口。打开窗口会显示光标并屏蔽角色移动、相机鼠标控制及世界交互输入；关闭时恢复之前的光标状态。
- 鼠标悬停物品时显示只读详情；携带物品时，悬停格子显示可放置、受阻或可交换的颜色反馈。
- 左键拿取后在指定格放置；单栏内按权威事务移动、交换位置、合并同类堆叠或交换堆叠数量。落点和结果以库存提交及同步后的权威投影为准。
- 右键从可堆叠物品拿取一个；携带部分堆叠时可在原堆上继续增加数量，或放回原堆。`Shift + 右键` 打开数量面板；确认数量后选定落点，再提交指定位置拆分。
- 双栏中可在另一容器的指定空位转移或拆分，也可对准物品合并 / 交换。`Ctrl + 左键` 自动转移整堆到另一栏，优先合并同类堆叠，再放入首个可用空白矩形。
- `Esc` 取消当前拿取或停止等待操作结果；操作等待、完成、失败和超时会显示简短状态提示。库存操作是否最终生效以库存同步结果为准。
- 摘要显示占用格数、总格数、堆数、物品件数及因空间不足未显示的堆数。
- 可拖动网格空白处平移内容；滚轮纵向滚动，按住 `Shift` 滚轮横向滚动，携带物品时仍可滚动。正在携带物品或等待库存操作时，网格会停止拖动，避免把物品操作误作滚动。

## 尚未实现

此界面目前不提供装备 / 消耗操作、负重与估价、搜索或排序，也不支持拖拽物品；物品通过点击拿取并移动鼠标，再点击放置。`Ctrl + 左键` 快捷转移仅在双栏窗口中触发，并使用库存接收规则优先合并同类堆叠，再查找空白矩形。网格空白处拖动仅平移视图，不改变物品坐标。联机同库存移动、交换、合堆和指定落点拆分受服务端复核并同步位置与尺寸；纯客户端跨库存转移 / 拆分因缺少服务端访问会话而拒绝。

## 静态检查与人工检查

本次职责调整已通过 UI 程序集离线编译（使用现有 Unity 依赖）及场景组件、GUID 与开窗订阅的静态核对；未启动 Unity、未运行项目或直接测试。

人工在 Unity 中打开场景后，还需确认背包/箱子互斥与输入恢复、关闭后再次打开能显示最新库存，以及重复打开同一箱子、切换来源或禁用窗口后再请求打开时的会话行为。界面排版、悬停命中和操作等待/失败/超时表现仍需运行确认。
