## 2. 语义

### 2.1 定向投递（source key）

| 源（`GMPSignalsImpl.cpp:367-381`） | Unity |
|---|---|
| `ElmSrc == InSigSrc` | 条目 source 与发布 source **引用相等**（`ReferenceEquals`，不用 `Equals`） |
| `ElmSrc == FSigSource::AnySigSrc` | 条目 source == `EventBus.AnySource`（通配哨兵） |
| `SrcWorld.IsValid() && ElmSrc == SrcWorld` | **不做**（Unity 无 World 概念） |

- 订阅方 source 传**组件实例**（`this`）→ 只收该实例发出的消息；传 `EventBus.AnySource` → 收该频道全部来源。
- 发布方 source 传 `null` → **只**被通配订阅者收到（严格对齐源的相等判定，不做「null 视为通配」的宽容处理）。
- 「同键不同实例互不串台」是**表结构保证**的：内部按 `(channel, source)` 分列成独立条目列表，而不是派发时再筛选。
- 非通配来源的 `Publish` 会**额外向 `AnySource` 订阅者派发一轮**（对应源中 `AnySigSrc` 条目的独立匹配）。

### 2.2 同步派发

源注释原文：`GMP 的消息派发是同步的（同一游戏线程、同一调用栈内完成），因此消息化不会改变任何时序`。

- `Publish` **返回时**所有命中回调已执行完毕；无队列、无延迟、无协程、无下一帧投递。
- 订阅方可直接在回调里消费栈上传来的 `struct` 载荷（值传递），不需要拷贝到闭包。
- 允许回调内再次 `Publish`（重入）：`dispatchDepth` 计数保证集合在派发栈归零后才压实。

### 2.3 弱引用自动解绑

- 订阅条目持 `WeakReference<object>`（**不持有强引用**，否则「自动解绑」失效）。
- 存活判定 = `TryGetTarget` 成功 **且**（`target is UnityEngine.Object uo` ? `uo != null` : `true`）—— Unity 对象被 `Destroy` 后托管包装仍存在，必须走 Unity 的 `==` 重载。
- 失效剔除双轨：① 派发时惰性剔除（对应源 `H.IsStale()` 分支）；② `PruneDeadListeners()` 主动回收（对应源 `ReclaimInactive`）。
- `SubscriptionCount(...)` 只统计**存活**条目，因此「监听者销毁后计数归零」无需等待回收时机。

### 2.4 签名校验与异常隔离

| 场景 | 行为 | 源 |
|---|---|---|
| 泛型个数 / 逐位类型与订阅声明不一致 | `BackpackLog.Warn` + 跳过该条目，**不抛异常** | `GMP_WITH_DYNAMIC_CALL_CHECK` |
| 单个回调抛异常 | 捕获 + `BackpackLog.Error`（含频道与回调宿主类型），**继续派发其余监听者** | 源为同步透传（**有意偏差**，见 §6 #4） |
| 空频道键 | `Warn` + 忽略（键必须取自三常量类） | `MIS_MessageKeys.h` 注释 3：键必须集中定义 |
| 非主线程调用 | `Warn` + 忽略 | `GMP_VERIFY_GAME_THREAD` |

### 2.5 订阅、退订与句柄

- `Subscribe(channel, source, listener, callback)` 四个重载（0/1/2/3 参），返回 `EventSubscription`。
- `listener` 是**弱引用锚点**，必传；传 `null` 视为常驻强订阅并给 `Warn`。
- 退订三条重载：`Unsubscribe(handle)`、`Unsubscribe(channel, listener)`（该频道全部来源）、`Unsubscribe(channel, listener, source)`（精确定位某一发送方），另有 `UnsubscribeAll(listener)`。
- **派发期修改安全**：回调内 `Subscribe` / `Unsubscribe` 不会抛 `InvalidOperationException`；本轮派发使用开始时的条目计数快照，新增订阅从下一轮生效，`Unsubscribe` 立即失效（后续快照不再命中）。

### 2.6 全局实例

- `EventBus.Global` 供业务层使用；需要互不干扰时（隔离场景、工具）用 `new EventBus()`。
- `Global` 带 `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]` 复位（关闭 Domain Reload 时静态字段不重置，与 F4/F5 同口径）；另有 `ResetGlobal()` 供显式重启路径调用。

## 4. 用法

```csharp
// 订阅（数据层组件实例作 source key；listener 传 this，弱引用锚点）
EventBus.Global.Subscribe(InvChannels.StackChanged, this, this, OnStackChanged);

// 订阅通配来源（该频道任意实例的消息）
EventBus.Global.Subscribe(InvChannels.MenuToggled, EventBus.AnySource, this, OnMenuToggled);

// 发布（同步：返回时回调已执行）
EventBus.Global.Publish(InvChannels.StackChanged, this, new SlotAvailabilityResult(...));
EventBus.Global.Publish(UiChannels.GridSlotClicked, this, tileIndex, UiChannels.MouseButton.Left);

// 显式退订（可选；不管也可，监听者销毁即自动解绑）
EventSubscription subscription = EventBus.Global.Subscribe(CmdChannels.DropItem, this, this, OnDropItem);
subscription.Dispose();
```

`Core` 不引用 `Items` / `Inventory`（`references` 保持 `[]`），载荷类型由**调用方泛型实参**决定；签名必须与 §3 表中一致。

## 5. 公开 API

| 成员 | 说明 |
|---|---|
| `static object AnySource` | 通配来源哨兵，用于「接收该频道全部来源」 |
| `static EventBus Global` | 全局实例（懒建）；`ResetGlobal()` 显式丢弃；域重载时自动复位 |
| `Subscribe(...)` ×4 | 0/1/2/3 参回调重载，返回 `EventSubscription` |
| `Publish(...)` ×4 | 0/1/2/3 参载荷重载；同步派发 |
| `Unsubscribe(int handle)` / `(channel, listener)` / `(channel, listener, source)` | 三条退订重载，返回受影响条目数 |
| `UnsubscribeAll(object listener)` | 退订该监听者全部订阅 |
| `Clear()` | 清空全部订阅（保留实例） |
| `IsAlive(channel, listener)` / `(channel, listener, source)`、`IsAliveHandle(int)` | 存活查询（供 `EventSubscription.IsAlive`） |
| `PruneDeadListeners()` | 主动回收失效条目，返回剔除数 |
| `SubscriptionCount(channel)` / `(channel, source)` | 只统计存活条目 |

`EventSubscription`：`IsAlive`、`Dispose()`（幂等）、`ToString()`；`default(EventSubscription).Dispose()` 安全。

## 6. 与源实现的有意偏差

| # | 偏差 | 源 | 本工程 | 理由 |
|---|---|---|---|---|
| 1 | source key 表达 | `FSigSource` = 裸地址 + 低位标记 | `object` 引用相等 | 托管环境无裸指针；Unity 无 World/External 来源概念 |
| 2 | 生命周期判定 | `FWeakObjectPtr` + `IsStale()` | `WeakReference<object>` + Unity 空判定 | 等价语义；额外覆盖「Unity 对象已 Destroy 但托管包装仍在」 |
| 3 | 载荷传递 | 反射参数表 + 按地址零拷贝 | 泛型实参 0–3 参 + 逐位 `Type[]` 校验 + 强转直调 | 零反射、零 `object[]` 分配 |
| 4 | 回调异常 | 同步透传 | 捕获 + `Error` + 继续派发 | 一个 UI 回调报错不应吞掉整条广播 |
| 5 | `Times` 订阅次数上限 | `FGMPListenOptions.Times` | **不做** | 源插件 0 处使用非默认值 |
| 6 | 日志模块位 | 源用 `DebugSystem` 变量控制 | 归入 `LogModule.Inventory` | F4 的 `LogModule` 无 Core 位，新增位会改动已定契约 |
| 7 | 频道键命名 | `MIS.Inv.ItemAdded` | `Inv.Item.Added` | 《F1_F2》§3.4 已冻结 `域.对象.动作` |

移植轮次偏差（相对蓝本工程）：① 命名空间前缀 `ZDXT` → `RPG4`；② 频道键 **11 → 9**（剔除 `Inv.PickupPrompt` / `Inv.Equipment.Changed`，M4/M7 再补）；③ **未移植** `Core/Editor/EventBusSelfCheck.cs` 与 `Core.Editor` 程序集（用户选型）。除这三项外与蓝本源码逐字节一致。
