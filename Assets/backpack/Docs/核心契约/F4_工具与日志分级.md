## 2. `GridUtils` 逐函数映射

> **本工程已落盘（2026-10-05，随 F3 一并补齐）**，本节契约与实际实现逐函数一致。

### 2.1 坐标换算（原样照搬公式）

| 源 | Unity | 公式 |
|---|---|---|
| `GetIndexFromPosition(const FIntPoint& Position, const int32 Columns)` | `GetIndexFromPosition(GridCoord coord, int columns)` | `coord.Y * columns + coord.X` |
| `GetPositionFromIndex(const int32 Index, const int32 Columns)` | `GetPositionFromIndex(int index, int columns)` | `new GridCoord(index % columns, index / columns)` |

- **参数类型由 `FIntPoint` 换成 F3 的 `GridCoord`**，落实蓝本《F3_网格类型契约》第 5 节第 1 条：换算只接受 `GridCoord`，不得另立第二套坐标类型。
- 前提条件：`columns > 0`（源工程同样未做守卫，除零会直接抛异常，属调用方契约）。
- **不引入第二种口径**：不得再出现 `row * width + col` 之类的散落写法。

### 2.2 Bounds 判定与 Clamp

| 源 | Unity | 语义 |
|---|---|---|
| `UMIS_InventoryGrid::IsInGridBounds(StartIndex, ItemDimensions)` | `IsInGridBounds(int startIndex, GridCoord itemDimensions, int columns, int rows)` | 以「起点索引 + 物品尺寸」推右上角边界，横纵均不得越界 |
| `IsWithinBounds(BoundaryPos, WidgetSize, MousePos)` | `IsWithinBounds(Vector2 boundaryPos, Vector2 widgetSize, Vector2 point)` | 点是否在矩形内，**闭区间** |
| `GetClampedWidgetPosition(Boundary, WidgetSize, MousePos)` | `GetClampedWidgetPosition(Vector2 boundary, Vector2 widgetSize, Vector2 point)` | 右 / 下越界则整体左移 / 上移，再对 0 取 Max |
| — | `ClampToGrid(GridCoord coord, int columns, int rows)` | **对齐补充**，见偏差 #3 |

- `IsInGridBounds` 源为**网格类成员**，依赖 `Columns` / `Rows` / `GridSlots.Num()` 三个字段；
  本类**下沉为纯函数**，`StartIndex >= GridSlots.Num()` 以 `startIndex >= columns * rows` 等价表达。
  M6 的网格类仍应保留同名成员函数包一层，使源调用点 `if (!IsInGridBounds(...)) continue;` 逐字可迁。
- `GetClampedWidgetPosition` 是**回折语义**（整体位移一个控件宽高），**不是**逐轴 `Mathf.Clamp`，替换会导致弹窗贴着右边界时被压扁位置错位。

### 2.3 二维遍历 `ForEach2D`（行优先）

| 源 | Unity | 回调 |
|---|---|---|
| `ForEach2D(int32 Columns, int32 Rows, LambdaType Lambda)` | `ForEach2D(int columns, int rows, Action<int, int, int> action)` | `(row, column, index)` |
| `ForEach2D(TArray<T>& Array, int32 Index, FIntPoint Range2D, int32 GridColumns, FuncT)` | `ForEach2D<T>(IList<T> slots, int startIndex, GridCoord dimensions, int columns, Action<T> action)` | 容器元素 |
| — | 同上逻辑的「索引 + 坐标」版 `ForEach2D(int startIndex, GridCoord dimensions, int columns, Action<int, GridCoord> action)` | `(index, coord)` |

- 三者的**行优先顺序一致**：外层行（`j` 由 0 递增）、内层列（`i` 由 0 递增），与 `SlotAvailabilityResult` 明细顺序对齐（蓝本《F3_网格类型契约》第 5 节第 2 条）。
- **越界保护与源一致**：区域版只做容器索引有效性判定（`index >= 0 && index < slots.Count`），
  **不额外做「列溢出回绕到下一行」的行边界判定**——源工程靠调用前的 `IsInGridBounds` 守卫，本工程沿用同一分工。
- 源区域内坐标为 `GetPositionFromIndex(Index, Columns) + FIntPoint(i, j)`，本类在循环外**只算一次原点**，循环内只做加法与一次乘法（与源逐格重算等价但少两次除法）。

## 3. 日志分级映射

### 3.1 选型替换（偏离源工程，已确认）

源工程 `DebugSystem` 是「**系统位掩码 + 四通道**」模型（`DS_LOG` / `DS_LOG_WARN` / `DS_LOG_ERR` / `DS_SCREEN` / `DS_PRINT` / `DS_PRINT_EX`），
**没有级别枚举**。本工程改用 Unity 惯例的**六级等级制 + 模块位掩码**，作为功能等价替换：

| 源 | Unity |
|---|---|
| `EDS_System` 位掩码（32 位） | `LogModule` 位掩码（`[Flags]`，7 个模块 + `None` + `All`） |
| `DS_LOG`（Log 通道） | `BackpackLog.Trace / Debug / Info` → `UnityEngine.Debug.Log` |
| `DS_LOG_WARN`（Warning 通道） | `BackpackLog.Warn` → `UnityEngine.Debug.LogWarning` |
| `DS_LOG_ERR`（Error 通道） | `BackpackLog.Error / Fatal` → `UnityEngine.Debug.LogError` |
| `DS_SCREEN` / `DS_PRINT` / `DS_PRINT_EX`（屏幕通道） | **不移植**（用户决策：屏幕调试留到 M5） |
| `debug.system.enable`（CVar） | `LogSettings.IsEnabled`（资产字段） |
| `debug.system.systems`（CVar 位掩码） | `LogSettings.EnabledModules`（资产字段） |
| `DS_ENABLED(System)` 在 Shipping 展开 `(void)0` | 方法体包 `#if UNITY_EDITOR || DEVELOPMENT_BUILD` |
| 宏内 `if (DS_ENABLED(...))` 先判开关 | `Func<string>` 惰性重载 + 公开 `IsEnabled(module, level)` |

### 3.2 `LogLevel`（六级）

`Trace = 0` / `Debug = 1` / `Info = 2` / `Warn = 3` / `Error = 4` / `Fatal = 5`。

**数值即严重度**，可直接用整数比较实现「最低级别」过滤（`level >= MinimumLevel`），单测/后续按位序断言不得漂移。

### 3.3 `LogModule`（位掩码）

| 模块 | 位 | 源 |
|---|---|---|
| `None` | 0 | `EDS_System::None` |
| `Inventory` | `1 << 0` | `EDS_System::Inventory` |
| `Equipment` | `1 << 1` | `EDS_System::Equipment` |
| `UI` | `1 << 2` | `EDS_System::UI` |
| `Network` | `1 << 3` | `EDS_System::Network` |
| `Interaction` | `1 << 4` | `EDS_System::Interaction` |
| `Combat` | `1 << 5` | `EDS_System::Combat` |
| `SaveLoad` | `1 << 6` | `EDS_System::SaveLoad` |
| `All` | `~0` | `EDS_System::All` |

**不移植**源工程的 `AI`(0x40) / `DataAsset`(0x100) / `Config`(0x200) 与 `Custom1~4`（0x10000000 起）共 7 项：
在源工程中同样无有效调用点，属预留位，与蓝本《F3_网格类型契约》对死代码的处理口径一致（偏差 #8）。

### 3.4 `LogSettings`（资产）

| 字段（camelCase，无下划线） | 类型 | 默认 | 作用 |
|---|---|---|---|
| `isEnabled` | `bool` | `true` | 全局开关 |
| `minimumLevel` | `LogLevel` | `Info` | 最低输出级别 |
| `enabledModules` | `LogModule` | `All` | 模块位掩码 |
| `useTimestamp` | `bool` | `true` | 是否加 `HH:mm:ss.fff` 时间戳 |
| `includeStackTrace` | `bool` | `false` | 是否额外追加 `Environment.StackTrace` 文本 |

- 资产位置：`Data/LogSettings.asset`（**F4 不新建 `Resources/` 目录**）。
- 判定链：`IsEnabledFor(module, level) = isEnabled && level >= minimumLevel && (enabledModules & module) != 0` —— 三个条件**全部**通过才输出。
- `CreateRuntimeDefault()` 生成 `HideFlags.HideAndDontSave` 的临时实例，供未注入资产时兜底，不落盘。

### 3.5 `BackpackLog`（入口）

- **不自动持有资产引用**。注入优先级：
  ① `BackpackLog.Settings = <asset>` 显式注入（推荐由启动流程 / Bootstrap 赋值）；
  ② `Resources.Load<LogSettings>("LogSettings")` 兜底（任一 `Resources/` 目录下的同名资产即可命中，F4 不新建该目录，仅预留钩子）；
  ③ 运行时默认值（`Info` 级别 + 全模块放行）。
- **惰性求值**：「字符串版」先判开关再输出；「`Func<string>` 版」在开关未通过时**不调用工厂**（对应源宏外层的 `DS_ENABLED` 判断，避免热点白拼字符串）。
- **发布构建零开销**：所有方法体（含私有 `Write` / `WriteLazy`）被 `#if UNITY_EDITOR || DEVELOPMENT_BUILD` 包住，Release 下彻底消除。
- **无屏幕通道**：只走 `UnityEngine.Debug`。类内一律写全限定 `UnityEngine.Debug.XXX`，避免与自身的 `Debug(LogModule, string)` 方法名歧义。
- 静态状态随 Domain Reload 复位：`[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` 内清空 `settings`，防止「进入播放模式选项」关闭 Domain Reload 时残留上一局配置。

## 5. 对后续阶段的硬约束

1. **M2 / M6**：一切 Index↔Position 换算只能走 `GridUtils.GetIndexFromPosition / GetPositionFromIndex`，**禁止**在业务代码里出现 `row * columns` 或 `% columns` 的裸算式。
2. **M6**：区域遍历一律用 `ForEach2D`（三签名任选），**禁止**双层 `for` 裸循环展开网格；象限落点相关的 `CalculateStartingCoordinate` / `CalculateTileQuadrant` 在 M6 落地，**内部必须复用 `GridUtils` 的换算**，不得重写。
3. **M6**：`ForEach2D` 的**行优先顺序**是 `SlotAvailabilityResult` 明细顺序的契约来源，任何「并行遍历」或顺序调整都视为破坏契约（源系统同此约定）。
4. **M5**：弹窗类定位用 `GetClampedWidgetPosition`（回折语义），画布进出判定用 `IsWithinBounds`（闭区间）；不得自行改写判定口径。
5. **全层**：日志一律通过 `BackpackLog`，禁止裸调 `UnityEngine.Debug.Log` 或 `print()`；模块从 `LogModule` 中按层选择（`Items/Inventory` → `Inventory`，`Equipment` → `Equipment`，`UI` → `UI`，网络复制 → `Network`）。
6. **热点路径**：需要拼字符串的日志必须用 `Func<string>` 重载或外层 `IsEnabled` 守卫。
7. **资产**：`LogSettings.asset` 为单例配置；如需按环境切换，**新增资产实例**而不是在运行时代码里硬编码字段。显式注入优先，`Resources` 兜底为可选（启用前须先改本工程 `Docs/工程架构/F1_F2_程序集与目录命名规范.md` 第 2 节目录树，新增 `Resources/`）。

## 7. 常用写法（供 M 阶段直接抄）

```csharp
// 换算
int index = GridUtils.GetIndexFromPosition(tileParams.TileCoordinates, columns);
GridCoord coord = GridUtils.GetPositionFromIndex(index, columns);

// 落点合法性（源：if (!IsInGridBounds(GetIndexFromPosition(Position, Columns), Dimensions)) return Result;）
if (!GridUtils.IsInGridBounds(index, dimensions, columns, rows)) return;

// 区域遍历（源形态：ForEach2D(GridSlots, Index, Dimensions, Columns, slot => ...)）
GridUtils.ForEach2D(gridSlots, index, dimensions, columns, slot =>
{
    slot.SetInventoryItem(newItem);
    slot.SetUpperLeftIndex(index);
});

// 惰性日志（热点路径）
BackpackLog.Debug(LogModule.Inventory, () => $"PickedUp | {item.name} | idx={index}");
```
